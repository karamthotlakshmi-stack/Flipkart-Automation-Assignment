# 🛒 Flipkart Automation Testing Project

## 📌 Project Overview
This project is an automated testing framework built for validating key functionalities of the Flipkart application. It follows a structured approach using Java and standard test automation practices.

The framework ensures:
- Functional correctness
- UI validation
- Reliable execution of test cases

---

## 🧰 Tech Stack
- Language: Java  
- Build Tool: Maven  
- Automation Tool: Selenium WebDriver  
- Testing Framework: TestNG / JUnit  
- IDE: Eclipse / IntelliJ  

---

## 📁 Project Structure
```
.
├── .Screenshots        # Captured screenshots during execution
├── .settings           # IDE configuration files
├── screenshots         # Runtime failure screenshots
├── src
│   ├── main
│   │   ├── java        # Core framework / utility code
│   │   └── resources   # Config files
│   └── test
│       ├── java
│       │   └── FlipkartTask   # Test cases
│       └── resources          # Test data
└── target              # Compiled files and reports
```

## ▶️ How to Run Tests

### Clone Repository
```
git clone https://github.com/karamthotlakshmi-stack/Flipkart-Automation-Assignment.git
cd FlipkartAutomation
```

### Install Dependencies
```
mvn clean install
```

### Run Tests
```
mvn test
```
